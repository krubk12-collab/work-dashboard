# ห้องทำงานครูโน้ต 🎮

Landing Page / Dashboard สไตล์ Gamification — แสดงภาพรวมการทำงานของครู
ผ่านตัวการ์ตูนน่ารัก 4 ตัวในห้องทำงาน

| ตัวละคร | คุมงานด้าน |
|---------|-----------|
| 🐮 โควัว | งานสอน / บันทึกการสอน |
| 🐱 แมว | งานเว็บแอป / โปรเจกต์ |
| 🐰 กระต่าย | งานนักเรียน |
| 🐼 แพนด้า | งานส่วนตัว / To-do |

## โครงสร้าง
- `index.html` — หน้าเว็บทั้งหมด (HTML+CSS+JS ในไฟล์เดียว)
- `assets/` — รูปพื้นหลังห้อง (`room.png`) + ตัวละคร PNG พื้นหลังใส (`cow/cat/rabbit/panda.png`)
  - ถ้ายังไม่มีไฟล์รูป หน้าเว็บจะใช้ห้องวาดด้วย CSS + ตัวการ์ตูน emoji แทนอัตโนมัติ

## ข้อมูล
ตอนนี้ใช้ข้อมูลจำลอง (`DATA` ใน index.html)
ภายหลังจะดึงจริงจาก Google Sheet ผ่าน Google Apps Script Web App (**GET เท่านั้น**)

## Host
GitHub Pages — branch `main`, root
